# ALGO COCKPIT - Algorithm and Code Optimizer

A web application to evaluate, optimize, and format competitive programming solutions using a 4-tier AI cascade (Gemini, GitHub Models, Groq, OpenRouter). Built specifically for C++17.

## Tech Stack
* Python (Flask)
* HTML, CSS, JavaScript
* Vercel

## Local Setup
1. Clone the repository.
2. Install requirements:
   pip install -r requirements.txt
3. Create a .env file and add your API keys (reference .env.example).
4. Run the application:
   python main.py

## Deployment
Configured for serverless deployment on Vercel using the included vercel.json file.
